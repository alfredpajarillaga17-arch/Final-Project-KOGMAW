Project OverviewK.O.G.M.A.W. is a centralized Java application featuring a user-friendly GUI that allows IT support staff and repair technicians to seamlessly log, search, update, and manage repair tickets and statuses in real time. It addresses the inefficiencies, lost tickets, and disorganized workflows common in manual logbook systems.Unlike standard applications that rely on built-in libraries, the core engine of K.O.G.M.A.W. is powered entirely by custom-built Data Structures and Algorithms (DSA) to handle memory, search caching, priority queuing, and workflow mapping. 

Core Data Structures ImplementedThe system's DataManager acts as a Singleton Master Clipboard, managing the following custom Abstract Data Types (ADTs):Custom Linked List: Dynamically stores sequential repair logs and linear history.Custom Queue: Enforces strict First-In, First-Out (FIFO) logic for incoming repair orders.Custom Hash Table: Delivers rapid $O(1)$ average lookups for caching active repair tickets via their unique Ticket ID.Custom Binary Search Tree (BST): Organizes records hierarchically, allowing $O(\log N)$ instant searches for the GUI search bar.Custom Heap (Priority Queue): Automatically reorganizes urgent tickets to index 0 based on Date and Repair Phase weight.Custom Graph: Models the multi-stage technical repair workflows using an adjacency matrix to validate state transitions.

Algorithms UtilizedGraph Traversal: Breadth-First Search (BFS) and Depth-First Search (DFS) for mapping out repair stages.Sorting: In-place Bubble Sort and Selection Sort for comparing performance metrics across large datasets.Searching: Recursive BST traversal, Hash Table chaining for collision resolution, and Linear Scanning.

Developer & Testing ToolsThe project includes a dedicated Testing package that bypasses the GUI for system evaluation:DataCreation.java / Test5000Runner.java: Automated factory that seeds the MySQL database with thousands of randomized dummy tickets.TestRunner.java: Runs automated QA unit tests (T01 - T10) on all custom data structures.BenchmarkRunner.java: Pushes sorting algorithms to their limits across 100 to 5,000 records, printing $O(N^2)$ performance metrics (Time in ns / Movements).TracePacketRunner.java: Provides step-by-step console outputs tracing memory states (Initial vs Final) during key operations (e.g., Hash Collisions, Heap insertions).
